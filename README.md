## 🛠️ The Core Weaponry (System Frameworks)

### 🎯 1. Project GapLogic — Retail Arbitrage Sniper
* **Domain:** Backend Architecture, High-Speed Web Automation, Market Intelligence
* **Core Stack:** Python, Django, Playwright, PostgreSQL, Market APIs
* **Overview:** An automated programmatic market tracker designed to identify price disparities across digital platforms. The sniper engine targets high-value legacy electronics, vintage digital cameras, and luxury decor, extracting price ceilings/floors and computing net profit variations while filtering market noise out in real-time.

### 🎨 2. Project CardFlow — Automated Content Pipeline
* **Domain:** Database Scalability, Dynamic Generation Layers, UI/UX Discovery
* **Core Stack:** Python, Flask, PostgreSQL, Asynchronous JavaScript, TailwindCSS
* **Overview:** A content creation and visual discovery pipeline built using a highly structured Pinterest-style masonry grid layout. Utilizes a powerful backend asset renderer to programmatically process custom multi-tenant design templates, typesetting vector graphics and typography data on the fly.
